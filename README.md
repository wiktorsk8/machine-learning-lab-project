# machine-learning-lab-project

Projekt: Credit Card Fraud Detection (Detekcja Anomalii)

## Szybki start
1. Zainstaluj zaleznosci:
   pip install -r requirements.txt
2. Uruchom notebook:
   jupyter notebook project.ipynb

## Dane
Notebook pobiera dataset z Kaggle przez `kagglehub` (mlg-ulb/creditcardfraud).
Upewnij sie, ze masz skonfigurowany dostep do Kaggle (token/API), aby pobranie dzialalo.
